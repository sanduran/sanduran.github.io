# PROJECTS
### A Flashcard App
**Thematic Area:** E-Learning  
**Problem Statement:** Students struggle to memorize large amounts of information using traditional study methods. There is a need for a simple digital solution that allows users to create and review flashcards efficiently.  
**Purpose:** The purpose of this project is to develop a mobile application that helps users learn and memorize information through digital flashcards.  
**Research:** Before developing the application, I did research on other similar apps. I also studied SwiftUI documentation and tutorials to understand best practices for iOS application development.  
**Technologies Used:** Swift Programming Language, SwiftUI, XCode  
**Process:** The project began with designing the basic structure of flashcards and presets. Classes were created to represent cards and collections of cards. I then added a user interface using SwiftUI.  
**Problems:** I learned that NavigationStack’s cant nest.  
**Conclusion:** The project successfully achieved its goal of creating a functional digital flashcard application.  
**Future Improvements:**
- Add a test functionality where users can take quick tests on the flashcards they created.
- Allow images on flashcards.
- Improve the visual design.
